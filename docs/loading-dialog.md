# LoadingDialog Component

## Purpose

`LoadingDialog` is a reusable UI component used to display a blocking loading state while the application performs an asynchronous operation.

It should be used when the user triggers an action that depends on a backend, database, network request, or any operation that may take noticeable time to complete.

Examples:

- Canceling an appointment
- Rescheduling an appointment
- Creating an appointment
- Saving profile changes
- Deleting a user
- Registering a barber
- Updating dashboard data
